# Smart API Gateway Next branding

Smart API Gateway Next is a branded distribution based on the open-source
[OmniRoute](https://github.com/diegosouzapw/OmniRoute) project.

## What changed

- The default interface language is Arabic and the application renders right-to-left.
- Product names, application metadata, desktop titles, colors, logos, and icons use the
  Smart API Gateway Next identity.
- The original OmniRoute license and attribution remain in [LICENSE](LICENSE).

## Compatibility

Internal package, executable, environment variable, protocol, and data-directory names may
continue to use `omniroute`. These technical identifiers are intentionally retained to preserve
compatibility with the upstream runtime and existing data.

The branded desktop auto-update channel is disabled until a dedicated Smart API Gateway Next
release repository is configured. This prevents an upstream desktop release from overwriting the
branded application.
